## 📌 Overview

AYUSH Virtual Herbal Garden is a modern full-stack web application that digitizes traditional herbal knowledge.
It allows users to explore medicinal plants, understand their healing properties, visualize them in 3D, and learn cultivation techniques.

The platform is designed with:

* 🌿 Clean & aesthetic UI
* ⚡ Fast performance using Vite
* ☁️ Real-time database (Firebase)
* 🧊 Interactive 3D models

---

## ✨ Key Features

### 🌱 Plant Exploration

* Search plants by name, disease, or medicinal use
* Filter by categories like Immunity, Digestion, Skin Care

### 🗺️ Explore by Location

* Interactive India map
* Discover plants region-wise

### 📖 Detailed Plant Pages

* Overview & description
* Medicinal uses
* Research papers
* Quiz system

### 🧊 3D Visualization

* Interactive 3D plant models
* Rotate models & view in AR

### 🎥 Learning Section

* “How to Grow” tutorials (video-based)

### 🧑‍💼 Admin Panel

* Add plant data
* Upload models (Cloudinary)
* Store & manage data using Firebase

## ⚙️ Project Setup

### 📥 Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/virtual-herbal-garden.git
cd virtual-herbal-garden
```

### 📦 Step 2: Install Dependencies

```bash
npm install
```

### ▶️ Step 3: Run Development Server

```bash
npm run dev
```

---

## 🏗️ Build & Deployment

### 🔨 Build Project

```bash
npm run build
```

### 🚀 Deploy on Firebase

```bash
npm install -g firebase-tools
firebase login
firebase init
firebase deploy
```
